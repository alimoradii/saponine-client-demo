# ساپونین · گالری محصولات

وب‌سایت مستقل HTML/CSS/JS با فونت محلی IRANSans، لوگوی رسمی ارسالی، رنگ‌های بنفش/یاسی/خاکستری و عکس‌های واقعی دوربری‌شدهٔ محصولات.

فایل index.html را از یک وب‌سرور استاتیک ارائه کنید. ناوبری، جستجو، فیلتر، انتخاب محصول، جزئیات و فرم آماده‌سازی متن درخواست فعال‌اند. ارسال واقعی فرم و ذخیرهٔ اطلاعات در این دمو فعال نیست.

منابع هویت و عکس‌ها در assets/brand-identity.json و assets/official-photo-sources.json ثبت شده‌اند. جزئیات توسعه و بررسی کیفیت در README اصلی مخزن و design-qa.md موجود است.

اسلایدر جدید: پنج عکس واقعی با محصول و متن هماهنگ، پخش خودکار ۷ ثانیه‌ای، توقف، قبلی/بعدی، انتخاب مستقیم، کنترل صفحه‌کلید و حرکت افقی. منابع عکس‌های محیطی در assets/slider-photo-sources.json ثبت شده‌اند. عکس‌های محیطی آرشیوی‌اند و به‌عنوان تصویر کارکنان یا محل شرکت معرفی نمی‌شوند.
