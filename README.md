# Saponine website concepts

Three independent Persian RTL static website demos. Each directory contains
its own HTML, CSS, JavaScript, assets and supplied IRANSans regular/bold fonts.

| Directory | Visual direction | Render publish directory |
| --- | --- | --- |
| `source/` | Cream/green brand presentation with product imagery | `source` |
| `motion/` | Scroll-driven 3D product story | `motion` |
| `reference/` | Full-screen layout following the Adrian Salamat reference | `reference` |

No package installation or build is required. Serve a selected directory with
any static HTTP server. Render Static Site build command: `true`.

Existing live demos:
- https://saponine-client-demo.onrender.com/
- https://saponine-motion-demo.onrender.com/

The reference demo is published as a separate Render Static Site using
`reference` as the publish directory. All demo data, collection names and
packaging are design concepts awaiting approved company content. No forms
send messages or store submissions. These are HTML demos, not installable
WordPress themes. Demo indexing is disabled.
