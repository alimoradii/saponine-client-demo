# Product cutout workflow

Tool mode: built-in image editor (`image_gen`).
Use case: background-extraction.

Each original photograph was individually used as an edit target. The common
brief was: remove only the studio wall/table background and cast shadow; keep
the photographed product, its carton or blister, original perspective, colors,
materials, logos, Persian/English lettering and printed numbers; do not invent,
redesign, relabel or beautify the packaging. Output true alpha transparency,
complete edges, modest transparent padding, no props, backdrop or added shadow.

Subjects:
1. Sapo-Zinc 2% bottle together with its carton.
2. Bibacter 70% clear sanitizer tube, including its purple cap.
3. Povidone Iodine 10% bottle and light cap.
4. Permethrin 1% shampoo carton.
5. Vitamin B1 300 mg carton together with the photographed tablet blister.

The downloaded originals and per-image source URLs/hashes remain available in
each demo assets directory. Cutout WebP files were losslessly encoded from the
editor output with RGBA pixel equality verified. No further pixel edits or
retouching were applied. CSS supplies the scroll/perspective motion.
